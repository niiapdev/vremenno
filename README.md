# 🤖 VK Subtitles Bot

VK-бот, который по ссылке на видео:
1. **Скачивает** видео
2. **Транскрибирует** речь (Whisper)
3. **Создаёт субтитры** (файлы `.srt`)
4. **Склеивает** видео с субтитрами (ffmpeg)

Бот написан на **Python 3.11+** (асинхронный, `asyncio`).

---

## 📁 Структура проекта

```
vk-subtitles-bot/
├── bot.py                        # ОСНОВНОЙ бот (EN-субтитры + склейка)
├── bot_subtitles_only.py         # Клон 1: только субтитры, без склейки
├── bot_subtitles_ru.py           # Клон 2: перевод EN→RU + склейка

├── requirements.txt              # Зависимости
├── video_for_whisper/            # где лежит скачанное видео
├── video_subtitled/              # куда бот кладёт результат
└── README.md                     # этот файл
```

## ⚙️ Как это работает (по шагам)

### 1. `downloader.py` — скачивание
- Принимает ссылку на видео.
- Через `yt-dlp` скачивает видео в папку `video_for_whisper/` с именем `%(id)s.%(ext)s`.
- Конвертирует в `mp4` (`FFmpegVideoConvertor`).
- Возвращает путь к файлу и название видео.

### 2. `translator.py` — транскрипция
- Загружает модель **Whisper** (`faster-whisper`, модель `medium`, CPU, `int8`).
- Делает транскрипцию аудиодорожки.
- Разбивает на сегменты с таймкодами.
- Сохраняет результат в SRT-файл: `{имя_видео}_en.srt`.
- Возвращает путь к SRT.

### 3. `merger.py` — склейка
- Через **ffmpeg** накладывает субтитры (`-vf subtitles=...`) на видео.
- Копирует аудиодорожку без перекодирования (`-c:a copy`).
- Результат: `{имя_видео}_subtitled.mp4`.
- Функция `cleanup_files()` удаляет временные файлы.

### 4. `bot.py` — VK-бот
- Слушает сообщения в VK.
- На `/start` — приветствие.
- На любую ссылку — последовательно скачивает → транскрибирует → склеивает, отправляя статус в чат, и кладёт готовый файл в `video_subtitled/`.

## 🧬 Клоны (bot_subtitles_only.py, bot_subtitles_ru.py)

| Файл | Что делает |
|------|-----------|
| `bot_subtitles_only.py` | Только скачивает видео и создаёт английский SRT, **не склеивая** его с видео. Видео и `.srt` (название — как у оригинала) кладёт в `video_subtitled/`, видео переносит туда же. |
| `bot_subtitles_ru.py` | Как оригинал, но переводит EN-субтитры на русский (`deep-translator` EN→RU) и склеивает видео с русскими субтитрами. |

## 🚀 Установка и запуск

### 1. Требования
- Python 3.11+
- **ffmpeg** в PATH (нужен для скачивания и склейки)
  - Windows: `winget install ffmpeg` или с http://ffmpeg.org
- Модель Whisper скачается автоматически при первом запуске (~1.5 ГБ)

### 2. Установка зависимостей
```bash
cd vk-subtitles-bot
python -m venv .venv                 # опционально
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Настройка токена
Создай **сообщество VK** → раздел «Управление» → «Работа с API» → группа-бот, получи токен.
Токен **не нужно хранить в коде** — положи в переменную окружения:

```bash
export VK_TOKEN="твой_токен"              # Linux/macOS
set VK_TOKEN="твой_токен"                 # Windows (cmd)
$env:VK_TOKEN="твой_токен"                # Windows (PowerShell)
```

Либо вставь в `config.py` в поле `VK_TOKEN` (дефолт — `YOUR_TOKEN_HERE`).

### 4. Запуск
```bash
python bot.py                # основной бот (EN + склейка)
python bot_subtitles_only.py # клон 1 (только субтитры)
python bot_subtitles_ru.py   # клон 2 (EN→RU + склейка)
```

Каждый клон — **отдельный независимый бот**, запускается своей командой.

### 5. Использование в VK
1. Открой диалог с ботом в VK.
2. Отправь `/start` — получишь приветствие.
3. Перешли ссылку на видео (например, ссылку из ВК, YouTube и т.д.).
4. Бот статусами покажет прогресс.
5. Готовый файл появится в папке `video_subtitled/`.

## 🔧 Примечания и особенности

- **Производительность**: транскрипция на CPU медленная; для больших файлов увеличь таймаут/мощность.
- **ffmpeg обязателен** — без него не работает ни скачивание (конвертация в mp4), ни склейка.
- **Язык**: основной бот генерирует английские субтитры; клон 2 дополнительно переводит их на русский.
- **Временные файлы** удаляются автоматически после обработки.

## 🧠 Промт для создания этого проекта (для ИИ)

> Создай VK-бота на Python (vkbottle), который по присланной в личные сообщения ссылке:
> 1) скачивает видео через yt-dlp в папку `video_for_whisper`,
> 2) делает транскрипцию через faster-whisper,
> 3) создаёт английские субтитры (файл `.srt`),
> 4) склеивает видео с субтитрами через ffmpeg,
> 5) готовый файл кладёт в папку `video_subtitled`.
>
> Раздели логику на модули: `config.py` (токен, пути), `downloader.py`, `translator.py`, `merger.py`, а `bot.py` только оркестрирует шаги и отвечает в чате.
> Сделай ещё 2 клона бота:
>   — один делает только субтитры (SRT), не склеивая их с видео, и видео переносит в ту же папку `video_subtitled` вместе с субтитрами (имя субтитров = имя оригинального видео);
>   — второй, как оригинал, но переводит английские субтитры на русский (deep-translator EN→RU) и склеивает видео с русскими субтитрами.
> Токен бота брать из переменной окружения `VK_TOKEN`, не хардкодить. Остальные файлы проекта не менять.

## 🐛 Известные ограничения
- Не поддерживаются ссылки на видео, требующие входа/подписки (yt-dlp вернёт ошибку).
- Очень длинные видео занимают много времени на транскрипцию.
- Субтитры вставляются «по расположению» (hard subtitle), убрать их после склейки нельзя.
